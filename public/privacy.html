Aviso de privacidad de TuTop — borrador beta

Este texto es un borrador operativo para pruebas privadas y requiere completar identidad/contacto del responsable y revisión legal antes de una publicación pública.

Datos usados en la beta

Número telefónico; nombre y facultad; publicaciones; mensajes; calificaciones; saldo de puntos UCoins y Puntos de Prestigio; fotografías de productos; reportes; y, cuando el usuario solicita verificación, evidencia de credencial estudiantil.

Durante esta beta el número sirve para crear una identidad de acceso en Firebase, pero no se verifica por SMS. TuTop no debe presentarlo como número verificado hasta que exista un mecanismo de verificación real.

Finalidades

Crear y proteger la cuenta, operar el marketplace universitario, permitir comunicación y coordinación de entregas, gestionar reputación, detectar abuso, atender reportes y solicitudes de verificación, y mantener la seguridad de la beta.

Infraestructura

La beta usa Firebase Authentication y Cloud Firestore. Las reglas de seguridad de Firestore y las operaciones atómicas limitan qué datos puede leer o modificar cada cuenta. En esta etapa no se usan Cloud Storage, Cloud Functions ni notificaciones push.

Pagos

TuTop no procesa ni custodia el pago de los productos físicos durante el MVP. El acuerdo de pago ocurre directamente entre estudiantes.

Eliminación

La eliminación automática todavía no está habilitada en la beta Spark. La página de eliminación de cuenta explica el procedimiento vigente y esta limitación. No se debe prometer un borrado automático desde la app hasta que el flujo exista y haya sido probado.

Seguridad

Movimientos de UCoins, pujas, reputación, moderación y verificación están restringidos mediante Firestore Security Rules y escrituras atómicas. Aun así, esta es una beta privada y requiere pruebas reales con el proyecto Firebase antes de considerarse lista para producción.

Última revisión del borrador: 3 de septiembre de 2026.
