Privacidad de TuTop — borrador beta

No es una política legal aprobada para publicación. Resume el comportamiento técnico observado en la candidata build110 y debe pasar revisión legal antes de una release pública.

Cuenta e identidad

TuTop usa Firebase Authentication. La candidata actual trabaja con correo real y estado de verificación de correo. El flujo de recuperación legacy puede partir de un alias telefónico existente y la Clave TuTop para conservar el mismo UID; ese teléfono sigue siendo opcional/no verificado y TuTop no lo presenta como verificado por SMS.

Datos y contenido usados por la beta

Según la superficie técnica revisada, TuTop puede manejar datos de perfil y universidad/campus; publicaciones y fotografías; chats y mensajes; ofertas, reservas y transacciones; favoritos, búsquedas guardadas, reseñas y reportes; preferencias de notificaciones; tokens de dispositivo para push; solicitudes de eliminación; y evidencia de verificación cuando el usuario usa ese flujo.

Ubicación

Nearby puede solicitar ubicación aproximada bajo demanda. La configuración nativa revisada usa ubicación coarse y no exige ubicación precisa ni ubicación en segundo plano para este flujo.

Topi / Firebase AI

Cuando se usa Topi con IA remota habilitada, una pregunta del usuario se sanea y limita antes de enviarse a Firebase AI Logic. La respuesta y el modelo regresan al cliente. El módulo local de diagnóstico revisado no conserva prompts, tokens, UID, teléfonos ni coordenadas.

Notificaciones

La candidata incluye soporte de Firebase Cloud Messaging y preferencias de notificación. El dispositivo puede registrar o desactivar un token push. La aceptación física extremo a extremo de FCM continúa pendiente y no debe confundirse con validación de código.

Fotos y video

El flujo de fotos puede usar Camera/Photo Picker y lectura local de archivos. El código de video/Firebase Storage existe detrás de feature flags, pero Storage/video permanece bloqueado en la candidata actual y no se declara aquí como una superficie activa de producción.

Eliminación de cuenta

Desde Perfil → Notificaciones y privacidad V2 → Eliminar cuenta y datos una cuenta autenticada puede registrar una solicitud de eliminación. La ejecución destructiva no se dispara automáticamente desde la app: existe un proceso controlado que separa datos eliminables, contenido que debe retirarse y evidencia operativa que podría requerir retención.

Ver información técnica sobre eliminación de cuenta.

Retención y revisión legal

Los plazos, bases jurídicas, excepciones de retención y aprobación final siguen pendientes de revisión legal. Este borrador no inventa esos elementos ni sustituye la declaración final de Data Safety de Google Play.

Infraestructura observada

En la superficie Android revisada aparecen Firebase Authentication/Firestore, Firebase AI Logic, Firebase App Check, Firebase Cloud Messaging y componentes Capacitor para Android, ubicación, cámara y filesystem.

Estado de publicación

TuTop continúa en beta controlada. Play Store, producción, billing, Storage/video y merge permanecen bloqueados por los gates actuales. Una política pública final debe ser coherente con el comportamiento real de la candidata que se publique.
